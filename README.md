# Daily DSA

A practical, day-by-day journey through Data Structures and Algorithms using Python.

## How this repository is organized

- `problems/` contains one problem per day.
- Each solution includes a clear approach, complexity analysis, and runnable code.
- The goal is consistent learning and genuine progress—not empty commits.
